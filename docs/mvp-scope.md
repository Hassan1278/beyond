# MVP scope

The current combined milestone is the private text MVP across web and Expo Android/iOS, with the original supplied design. See [current contracts, validation and remaining work](connected-app.md).

Included: Supabase account/auth/recovery/OAuth handoff and refresh; verified owner/session authorization; private journal CRUD/revisions/retries; preferences; explicitly approved/corrected memories; standalone todos; private paginated exports/content clearing and optional durable account deletion. The backend also provides per-entry reflection consent, next-local-morning durable jobs and an independent versioned AI HTTP handoff, result/correction storage and explicit accepted/rejected task decisions. Production provider generation stays deferred.

Real-user letter/pattern/theme/Wrapped areas are empty until actual results exist; fictional data appears only in explicitly marked demo/marketing/presenter modes. Undesigned areas remain empty. The pitch source is organized into existing web/mobile and a shared UI workspace, with one lockfile.

Remaining release gates: independent AI service/evaluations, hosted configuration/migrations/origins/email/Google/schedulers, and real Android/iOS/native build/device QA. The current UI is shared DOM inside Expo, preserving the supplied design. JS exports are preliminary validation.

Voice capture/private Storage/transcription/review is a later input feature and is disabled in the text MVP. Real theme analysis/Wrapped/Life Film, complex notifications, offline sync, social features, billing and broader attachments are outside this milestone. These require additional work; do not describe them as implemented or fabricate results. No end-to-end encrypted AI or perfect safety is promised.
